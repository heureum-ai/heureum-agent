# PDF 단축키 총정리

## Adobe Acrobat 단축키

### 탐색 (Navigation)

| 동작 | Windows | Mac |
|------|---------|-----|
| 확대 | `Ctrl + +` | `Cmd + +` |
| 축소 | `Ctrl + -` | `Cmd + -` |
| 페이지에 맞추기 | `Ctrl + 0` | `Cmd + 0` |
| 실제 크기 (100%) | `Ctrl + 1` | `Cmd + 1` |
| 너비에 맞추기 | `Ctrl + 2` | `Cmd + 2` |
| 보이는 영역에 맞추기 | `Ctrl + 3` | `Cmd + 3` |
| 전체 화면 | `Ctrl + L` | `Cmd + L` |
| 페이지 이동 | `Ctrl + J` | `Cmd + J` |
| 찾기 | `Ctrl + F` | `Cmd + F` |
| 고급 검색 | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| 다음 찾기 | `Ctrl + G` | `Cmd + G` |
| 시계방향 회전 | `Ctrl + R` | `Cmd + R` |
| 반시계방향 회전 | `Ctrl + Shift + R` | `Cmd + Shift + R` |

### 편집 (Editing)

| 동작 | Windows | Mac |
|------|---------|-----|
| 열기 | `Ctrl + O` | `Cmd + O` |
| 저장 | `Ctrl + S` | `Cmd + S` |
| 다른 이름으로 저장 | `Ctrl + Shift + S` | `Cmd + Shift + S` |
| 인쇄 | `Ctrl + P` | `Cmd + P` |
| 실행 취소 | `Ctrl + Z` | `Cmd + Z` |
| 다시 실행 | `Ctrl + Y` | `Cmd + Y` |
| 환경 설정 | `Ctrl + K` | `Cmd + K` |
| 문서 속성 | `Ctrl + D` | `Cmd + D` |
| 속성 바 표시/숨기기 | `Ctrl + E` | `Cmd + E` |

### 주석 및 마크업 (Comment & Markup)

| 동작 | Windows | Mac |
|------|---------|-----|
| 텍스트 하이라이트 | `Ctrl + Alt + J` | `Cmd + Alt + J` |
| 텍스트 밑줄 | `Ctrl + Alt + U` | `Cmd + Alt + U` |
| 텍스트 취소선 | `Ctrl + Alt + S` | `Cmd + Alt + S` |
| 텍스트 삽입 | `Ctrl + Alt + I` | `Cmd + Alt + I` |
| 스티키 노트 | `Ctrl + 6` | `Cmd + 6` |
| 스탬프 도구 | `Ctrl + 7` | `Cmd + 7` |
| 코멘트 추가 | `Ctrl + Alt + M` | `Cmd + Alt + M` |
| 코멘트 패널 열기 | `Ctrl + Shift + O` | `Cmd + Shift + O` |
| 파일 첨부 | `Ctrl + Shift + K` | `Cmd + Shift + K` |

### 페이지 관리 (Page Management)

| 동작 | Windows | Mac |
|------|---------|-----|
| 빈 페이지 삽입 | `Ctrl + Shift + T` | `Cmd + Shift + T` |
| 파일 삽입 | `Ctrl + Shift + I` | `Cmd + Shift + I` |
| 페이지 삭제 | `Ctrl + Shift + D` | `Cmd + Shift + D` |

### 단일 키 도구 선택 (환경 설정에서 활성화 필요)

| 도구 | 키 |
|------|-----|
| 손 도구 (이동) | `H` |
| 선택 도구 | `V` |
| 확대 도구 | `Z` |
| 오브젝트 선택 | `R` |
| 오브젝트 편집 | `O` |
| 자르기 도구 | `C` |
| 링크 도구 | `L` |
| 텍스트 필드 | `F` |
| 텍스트 편집 | `T` |
| 편집 마스킹 | `Shift + Y` |
| 임시 손 도구 | `Spacebar` |

### 접근성 (Accessibility)

| 동작 | Windows | Mac |
|------|---------|-----|
| 소리 내어 읽기 활성화 | `Ctrl + Shift + 5` | `Cmd + Shift + 5` |
| 현재 페이지 읽기 | `Ctrl + Shift + V` | `Cmd + Shift + V` |
| 끝까지 읽기 | `Ctrl + Shift + B` | `Cmd + Shift + B` |

## Foxit PDF Reader 단축키 (Mac)

| 동작 | 단축키 |
|------|--------|
| 파일 열기 | `Cmd + O` |

| 동작 | 단축키 |

## PDF.js 뷰어 단축키

| 동작 | 단축키 |
|------|--------|
| 다음 페이지 | `N`, `J`, `Space` (프레젠테이션) |
| 이전 페이지 | `P`, `K`, `Shift + Space` (프레젠테이션) |
| 사이드바 토글 | `F4` |
| 확대 | `Ctrl/Cmd + +` |
| 축소 | `Ctrl/Cmd + -` |
| 찾기 | `Ctrl/Cmd + F` |
