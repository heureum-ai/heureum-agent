# PDF 주석 및 마크업 기능 가이드

## 텍스트 마크업 도구

| 도구 | 설명 | 용도 |
|------|------|------|
| **하이라이트** | 텍스트 위에 반투명 색상 오버레이 | 중요 내용 강조 |
| **밑줄** | 선택한 텍스트에 밑줄 추가 | 핵심 용어 표시 |
| **취소선** | 텍스트 위에 선 긋기 | 삭제 대상 표시 |
| **물결 밑줄** | 물결 모양 밑줄 | 문제가 있는 텍스트 표시 |
| **텍스트 교체** | 교체할 텍스트 표시 + 대체 텍스트 제안 | 수정 요청 |

## 코멘트 도구

| 도구 | 설명 | 용도 |
|------|------|------|
| **스티키 노트** | 페이지 특정 지점에 팝업 메모 첨부 | 리뷰 코멘트 |
| **텍스트 박스** | 테두리가 있는 자유 위치 텍스트 | 추가 설명 |
| **말풍선 (Callout)** | 특정 콘텐츠를 가리키는 화살표 텍스트 | 지적 사항 표시 |
| **타이프라이터** | 페이지에 직접 텍스트 입력 | 폼에 직접 입력 |
| **프리 텍스트 (Free Text)** | 테두리 없는 텍스트 주석 | 간단한 메모 |

## 드로잉/도형 도구

| 도구 | 설명 | 용도 |
|------|------|------|
| **선 (Line)** | 직선 (화살촉 옵션) | 참조선 |
| **화살표 (Arrow)** | 방향 화살표가 있는 직선 | 방향 지시 |
| **사각형 (Rectangle)** | 직사각형 도형 | 영역 강조 |
| **타원/원 (Oval)** | 타원형 도형 | 특정 부분 원으로 표시 |
| **다각형 (Polygon)** | 다변형 닫힌 도형 | 복잡한 영역 표시 |
| **다중선 (Polyline)** | 다중 선분 열린 도형 | 경로 표시 |
| **구름 (Cloud)** | 구름 모양 주석 | 건설/건축 리뷰에서 사용 |
| **연필/잉크 (Pencil/Ink)** | 자유 드로잉 | 손글씨 메모 |
| **지우개 (Eraser)** | 잉크 주석 일부 제거 | 드로잉 수정 |

## 스탬프 도구

### 기본 스탬프 종류

| 카테고리 | 스탬프 |
|----------|--------|
| **승인/거절** | Approved, Rejected, Not Approved |
| **상태** | Draft, Final, Completed, Expired |
| **보안** | Confidential, For Public Release, Not For Public Release |
| **기타** | As Is, For Comment, Preliminary Results, Information Only |

### 스탬프 유형
- **표준 스탬프**: 미리 정의된 고정 스탬프
- **동적 스탬프**: 날짜/시간 및 사용자 정보 자동 포함
- **커스텀 스탬프**: 사용자가 만든 이미지 스탬프
- **이미지 스탬프**: 이미지 파일을 스탬프로 삽입

## 측정 도구

| 도구 | 설명 | 사용 분야 |
|------|------|-----------|
| **거리 (Distance)** | 두 점 사이 직선 거리 측정 | 건축, 도면 |
| **둘레 (Perimeter)** | 다중 선분 경로의 총 길이 측정 | 건설, 설계 |
| **면적 (Area)** | 닫힌 영역의 면적 측정 | 부동산, 건축 |
| **호 측정 (Arc)** | 곡선 거리 측정 | 기계 설계 |
| **교정 (Calibration)** | 실제 스케일 설정 | 정확한 측정을 위한 기준 설정 |

## 파일 첨부

- 파일을 PDF에 직접 주석으로 첨부 가능
- 페이지 특정 위치에 파일 아이콘 고정
- 참조 자료, 원본 파일 등을 함께 배포할 때 유용

## 코멘트 관리

### 기본 기능
- **답글 (Reply)**: 코멘트에 대한 스레드 토론
- **상태 설정**: Accepted, Rejected, Cancelled, Completed
- **필터 및 정렬**: 유형, 작성자, 날짜별 필터
- **내보내기/가져오기**: XFDF, FDF 형식 지원
- **요약**: 코멘트 전체 요약 보고서 생성
- **표시/숨기기**: 모든 코멘트 일괄 표시/숨기기
- **팝업 일괄 관리**: 모든 팝업 열기/닫기

### 협업 리뷰 워크플로우

```
1. 리뷰 시작 (Initiate Shared Review)
   ↓
2. 리뷰어에게 PDF 전송
   ↓
3. 각 리뷰어가 주석/코멘트 추가
   ↓
4. 코멘트 수집 및 통합
   ↓
5. 작성자가 코멘트 확인 및 반영
   ↓
6. 최종 승인 및 서명
```

## @heureum/pdf에서의 주석 기능

이 프로젝트에서 지원하는 주석 관련 기능:

- **`pdf_fill_annotations`**: 비정형 PDF에 FreeText 주석을 지정된 좌표에 추가
  - 커스텀 폰트, 폰트 크기, 색상 지원
  - 이미지-PDF 좌표계 변환 처리
  - 바운딩 박스 기반 정밀 위치 지정
- **`pdf_check_bounding_boxes`**: 주석 위치(바운딩 박스) 검증
  - 겹치는 영역 감지
  - 폰트 크기 대비 높이 적절성 확인
- **`pdf_create_validation_image`**: 주석 위치를 시각적으로 확인할 수 있는 이미지 생성
  - 빨간색: 입력 영역 바운딩 박스
  - 파란색: 라벨 바운딩 박스
