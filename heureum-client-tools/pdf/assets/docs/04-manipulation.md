# PDF 조작 기능 가이드

## 핵심 조작 기능

### 병합 (Merge/Combine)
- 여러 PDF 파일을 단일 문서로 결합
- 드래그 앤 드롭으로 페이지 순서 변경
- 서로 다른 문서의 페이지를 교대로 혼합
- 병합 중 페이지 방향 조정 가능

**도구**: Adobe Acrobat, PDFsam (무료/오픈소스), iLovePDF, Smallpdf

### 분할 (Split)
- 페이지 범위별 분할 (예: 1-5, 6-10)
- 북마크 기준 분할
- N페이지마다 별도 파일로 분할
- 특정 페이지를 개별 PDF로 추출
- 빈 페이지 자동 제거

**도구**: PDFsam, PDF Arranger, iLovePDF

### 회전 (Rotate)
- 개별 페이지 또는 전체 페이지 회전
- 90°, 180°, 270° 회전 지원
- 선택한 페이지 범위만 회전 가능

### 자르기 (Crop/Trim)
- 페이지 여백 자르기
- 커스텀 크롭 박스 설정
- 여백 자동 제거
- 인쇄용 블리드, 트림, 아트 박스 정의

### 추출 (Extract)

| 대상 | 설명 |
|------|------|
| 페이지 | 특정 페이지를 새 PDF로 추출 |
| 이미지 | PDF에 포함된 이미지 추출 |
| 텍스트 | 텍스트 콘텐츠 추출 |
| 폰트 | 임베드된 폰트 추출 |
| 폼 데이터 | 폼에 입력된 데이터 추출 |

### 압축/최적화 (Compress/Optimize)

| 방법 | 설명 | 효과 |
|------|------|------|
| 이미지 해상도/품질 축소 | DPI 낮추기, JPEG 품질 조정 | 높음 |
| 중복 리소스 제거 | 동일 폰트, 이미지 등 병합 | 중간 |
| 웹 최적화 (Linearize) | 빠른 웹 뷰잉을 위한 구조 변경 | 로딩 속도 향상 |
| 미사용 오브젝트 제거 | 참조되지 않는 객체 정리 | 중간 |
| 투명도 병합 (Flatten Transparency) | 투명 레이어 병합 | 중간 |
| 폰트 임베드 제거 | 시스템 폰트로 대체 | 높음 |

**최적화 대상별 설정**:
- **웹용**: 해상도 72-150 DPI, 색상 최적화
- **인쇄용**: 해상도 300 DPI 유지, 색상 보존
- **보관용**: PDF/A 표준 준수

### 평탄화 (Flatten)

> **주의**: 평탄화는 되돌릴 수 없으므로 반드시 백업을 유지하세요.

- **주석 평탄화**: 주석을 페이지 콘텐츠에 병합
- **폼 필드 평탄화**: 폼을 편집 불가능하게 변환
- **레이어 평탄화**: 모든 레이어를 단일 레이어로 병합

### 페이지 번호 매기기

| 유형 | 설명 | 사용 예시 |
|------|------|-----------|
| 머리글/바닥글 | 페이지 번호, 날짜, 텍스트 추가 | 일반 문서 |
| 베이츠 번호 (Bates Numbering) | 접두사/접미사 + 자동 증분 번호 | 법률 문서 |
| 로마/아라비아 숫자 | 섹션별 다른 번호 체계 | 학술 문서 |
| 커스텀 형식 | 사용자 정의 번호 형식 | 특수 문서 |

### 워터마크 (Watermark)

- **텍스트 워터마크**: "기밀", "초안" 등 텍스트 오버레이
- **이미지 워터마크**: 로고, 도장 등 이미지 오버레이
- **설정 옵션**: 투명도, 위치, 회전, 크기
- **적용 범위**: 전체 페이지 또는 특정 범위
- **프로필 저장**: 워터마크 템플릿 저장/재사용

## PDF 변환

### PDF로 변환 (To PDF)

| 원본 형식 | 비고 |
|-----------|------|
| Word (DOCX) | 서식 유지 |
| Excel (XLSX) | 표 레이아웃 유지 |
| PowerPoint (PPTX) | 슬라이드별 페이지 변환 |
| 이미지 (JPG, PNG, TIFF) | 해상도 유지 |
| HTML | 웹 페이지 캡처 |
| 이메일 | 첨부파일 포함 옵션 |

### PDF에서 변환 (From PDF)

| 대상 형식 | 비고 |
|-----------|------|
| Word (DOCX) | 편집 가능한 문서로 변환 |
| Excel (XLSX) | 표 데이터 추출 |
| PowerPoint (PPTX) | 슬라이드로 변환 |
| 이미지 (JPG, PNG, TIFF) | 페이지별 이미지 |
| HTML | 웹 페이지로 변환 |
| 텍스트 (TXT) | 순수 텍스트 추출 |

### OCR (광학 문자 인식)
- 스캔/이미지 PDF를 검색 가능한 텍스트로 변환
- 다국어 인식 지원 (한국어 포함)
- 오픈소스: OCRmyPDF, Tesseract

## @heureum/pdf에서의 조작 기능

이 프로젝트에서 제공하는 관련 도구:

```typescript
// PDF를 PNG 이미지로 변환
convertPdfToImages(inputPdfPath, outputDirectory, maxDim?)
// - pdftoppm 시스템 명령 사용
// - 바이큐빅 리샘플링으로 고품질 이미지 스케일링
// - 기본 최대 크기: 1000px
```
