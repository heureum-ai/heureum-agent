# PDF 접근성 기능 가이드

## 문서 구조 (Document Structure)

### 태그 PDF (Tagged PDF)

문서의 의미론적 구조를 정의하는 계층적 태그 시스템입니다.

| 태그 유형 | 설명 | 용도 |
|-----------|------|------|
| H1-H6 | 제목 수준 | 문서 구조 정의 |
| P | 단락 | 일반 텍스트 |
| L, LI | 목록, 목록 항목 | 순서/비순서 목록 |
| Table, TR, TH, TD | 표 구조 | 데이터 테이블 |
| Link | 링크 | 하이퍼링크 |
| Figure | 그림 | 이미지/차트 |
| Span | 인라인 텍스트 | 텍스트 속성 |
| Div | 블록 컨테이너 | 그룹화 |

### 핵심 접근성 요소

| 요소 | 설명 |
|------|------|
| **읽기 순서 (Reading Order)** | 보조 기술이 콘텐츠를 탐색하는 논리적 순서 |
| **아티팩트 (Artifacts)** | 장식적/비필수 콘텐츠 표시 (페이지 번호, 배경 등) |
| **대체 텍스트 (Alt Text)** | 이미지/그림에 대한 텍스트 설명 |
| **언어 지정** | 문서 및 콘텐츠의 언어 속성 |

## 접근성 검사 (Accessibility Checker)

### 검사 항목

| 카테고리 | 주요 검사 내용 |
|----------|---------------|
| 문서 | 태그 구조, 제목, 언어 설정 |
| 페이지 콘텐츠 | 읽기 순서, 아티팩트, 탭 순서 |
| 폼 | 필드 레이블, 탭 순서, 도구 설명 |
| 대체 텍스트 | 모든 이미지에 대한 대체 텍스트 존재 여부 |
| 표 | 머리글, 요약, 정규 구조 |
| 목록 | 적절한 목록 태그 사용 |
| 제목 | 논리적 제목 수준 순서 |

### 검사 워크플로우

```
1. 접근성 검사 실행
   ↓
2. 검사 결과 확인 (통과/실패/수동 검사 필요)
   ↓
3. 실패 항목 수정
   - 태그 추가/수정
   - 대체 텍스트 추가
   - 읽기 순서 조정
   ↓
4. 재검사
   ↓
5. 수동 검사 항목 확인
   - 색상 대비
   - 읽기 순서 논리성
   - 대체 텍스트 적절성
```

## 스크린 리더 지원

### 내장 기능
- **Read Out Loud**: 내장 TTS(Text-to-Speech) 기능
- **키보드 탐색**: 모든 대화형 요소를 키보드로 접근
- **포커스 표시기**: 폼 필드와 링크에 시각적 포커스 표시

### 호환 스크린 리더

| 스크린 리더 | 플랫폼 | 비고 |
|-------------|--------|------|
| JAWS | Windows | 가장 널리 사용 |
| NVDA | Windows | 오픈소스, 무료 |
| VoiceOver | macOS/iOS | Apple 내장 |
| TalkBack | Android | Google 내장 |

### 접근성 단축키 (Adobe Acrobat)

| 동작 | Windows | Mac |
|------|---------|-----|
| 소리 내어 읽기 활성화 | `Ctrl + Shift + 5` | `Cmd + Shift + 5` |
| 현재 페이지 읽기 | `Ctrl + Shift + V` | `Cmd + Shift + V` |
| 끝까지 읽기 | `Ctrl + Shift + B` | `Cmd + Shift + B` |

## 리플로우 (Reflow)

- 스크린 리더 호환성을 위한 리플로우 뷰
- 동적 텍스트 크기 조정
- 콘텐츠가 화면 너비에 맞게 재배치

## 접근성 표준

| 표준 | 설명 | 주요 요구사항 |
|------|------|---------------|
| **PDF/UA (ISO 14289)** | PDF 범용 접근성 표준 | 임베드 폰트, 태그 구조, 대체 텍스트 |
| **WCAG 2.0/2.1/2.2** | 웹 콘텐츠 접근성 지침 | 인식/운용/이해/견고성 원칙 |
| **Section 508** | 미국 연방 접근성 요구사항 | 정보통신 기술 접근성 |
| **PDF/UA-2** | PDF 2.0 기반 업데이트 표준 | 향상된 시맨틱 태깅 |
| **KWCAG 2.2** | 한국 웹 콘텐츠 접근성 지침 | 국내 접근성 기준 |

## 접근성 PDF 제작 체크리스트

```
□ 모든 콘텐츠에 태그가 적용되어 있는가?
□ 논리적인 읽기 순서가 설정되어 있는가?
□ 모든 이미지에 적절한 대체 텍스트가 있는가?
□ 장식적 요소가 아티팩트로 표시되어 있는가?
□ 문서 언어가 지정되어 있는가?
□ 제목이 올바른 계층 구조를 따르는가? (H1 → H2 → H3)
□ 표에 머리글 셀(TH)이 지정되어 있는가?
□ 폼 필드에 설명/레이블이 있는가?
□ 링크 텍스트가 의미 있는가? ("여기 클릭" 대신 구체적 설명)
□ 색상 대비가 충분한가? (최소 4.5:1)
□ 폰트가 임베드되어 있는가?
□ 탭 순서가 논리적인가?
```
