# PDF 보안 기능 가이드

## 비밀번호 보호

| 유형 | 설명 | 용도 |
|------|------|------|
| **문서 열기 비밀번호 (User Password)** | PDF를 열고 보는 데 필요 | 문서 접근 제한 |
| **권한 비밀번호 (Owner Password)** | 허용되는 동작을 제어 | 편집/인쇄 제한 |

## 권한 제어

| 권한 | 옵션 |
|------|------|
| 인쇄 | 허용 / 거부 / 저해상도만 허용 |
| 콘텐츠 복사/추출 | 허용 / 거부 |
| 콘텐츠 편집/수정 | 허용 / 거부 |
| 코멘트/주석 | 허용 / 거부 |
| 폼 채우기 | 허용 / 거부 |
| 페이지 조립 | 삽입, 삭제, 회전 허용 여부 |
| 접근성 | 접근성 도구의 콘텐츠 추출 허용 |

## 암호화 표준

| 표준 | 보안 수준 | 권장 여부 |
|------|-----------|-----------|
| 40비트 RC4 | 매우 약함 | 사용 금지 |
| 128비트 RC4 | 약함 | 비권장 |
| 128비트 AES | 보통 | 조건부 허용 |
| **256비트 AES** | **강함** | **권장 (ISO 32000 기본)** |

## 인증서 기반 보안

```
암호화 프로세스:
┌────────────┐    ┌─────────────────┐    ┌──────────────┐
│  PDF 문서   │ → │ 수신자 공개키로   │ → │  암호화된 PDF  │
│            │    │ 대칭키 암호화     │    │              │
└────────────┘    └─────────────────┘    └──────────────┘

복호화:
┌──────────────┐    ┌─────────────────┐    ┌────────────┐
│  암호화된 PDF  │ → │ 수신자 개인키로   │ → │  복호화된 PDF │
│              │    │ 대칭키 복호화     │    │            │
└──────────────┘    └─────────────────┘    └────────────┘
```

- 디지털 인증서를 사용한 공개키 암호화
- 특정 수신자의 공개키로 암호화 → 해당 개인키 소유자만 복호화 가능
- 다중 수신자 지원

## 편집 마스킹 (Redaction)

> **핵심 차이**: 편집 마스킹은 데이터를 **영구 삭제**합니다. 검은색 오버레이(사각형 그리기)는 데이터를 **숨기기만** 할 뿐 삭제하지 않습니다.

### 프로세스

```
1. 편집 대상 표시 (Mark for Redaction)
   - 텍스트, 이미지, 영역 선택
   ↓
2. 검토 (Review)
   - 표시된 항목 확인
   ↓
3. 편집 적용 (Apply Redaction)
   - 콘텐츠 영구 삭제
   - 되돌릴 수 없음!
```

### 편집 마스킹 기능

| 기능 | 설명 |
|------|------|
| **텍스트/이미지/영역 선택** | 수동으로 편집할 콘텐츠 선택 |
| **검색 및 편집** | 특정 패턴 자동 검색 (주민번호, 이메일, 전화번호) |
| **편집 속성** | 오버레이 색상, 텍스트, 코드 커스터마이즈 |
| **일괄 편집** | 여러 항목을 한 번에 편집 |

## 문서 정리 (Sanitization)

### 숨겨진 정보 제거

| 대상 | 설명 |
|------|------|
| 메타데이터 | 작성자, 생성 도구, 날짜 등 |
| 코멘트 | 모든 주석 및 마크업 |
| 숨겨진 레이어 | 비표시 레이어 |
| 북마크 | 문서 개요/목차 |
| 첨부 파일 | 임베드된 파일 |
| 폼 필드 데이터 | 입력된 폼 데이터 |
| JavaScript | 문서에 포함된 스크립트 |
| 임베드된 검색 인덱스 | 문서 검색 데이터 |

### 문서 검사 (Examine Document)

공유 전 숨겨진 콘텐츠 스캔:
- 메타데이터
- 숨겨진 텍스트/레이어
- 외부 참조
- 주석/마크업
- 첨부파일 및 멀티미디어

## 디지털 권한 관리 (DRM)

| 기능 | 설명 |
|------|------|
| 정책 기반 문서 제어 | 세부 접근 권한 정의 |
| 원격 접근 취소 | 배포 후에도 접근 권한 철회 가능 |
| 사용 추적 | 누가 언제 열었는지 감사 로그 |
| 동적 워터마크 | 열람자 정보가 포함된 동적 워터마크 |
| 만료 설정 | 특정 날짜 이후 접근 차단 |

## 보안 체크리스트

```
□ 256비트 AES 암호화 사용
□ 강력한 비밀번호 설정 (12자 이상, 특수문자 포함)
□ 불필요한 권한 제거 (인쇄, 복사 등)
□ 민감 정보 편집 마스킹 적용 (오버레이가 아님!)
□ 공유 전 문서 정리 (메타데이터, 숨겨진 콘텐츠 제거)
□ 디지털 서명 적용 (무결성 보장)
□ 인증서 기반 암호화 (특정 수신자만 접근)
□ PDF/A 보관 시 보안 설정 확인
```
