# PDF 기업 실무 워크플로우

## 1. 문서 검토 및 승인 워크플로우

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  초안 작성 │ → │ 리뷰 요청  │ → │ 협업 리뷰  │ → │ 코멘트 수집│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      │
┌──────────┐    ┌──────────┐    ┌──────────┐          │
│   보관    │ ← │ 최종 승인  │ ← │  수정 반영  │ ←────────┘
│ (PDF/A)  │    │ (디지털 서명)│    │          │
└──────────┘    └──────────┘    └──────────┘
```

### 단계별 기능 활용

| 단계 | 사용 기능 |
|------|-----------|
| 초안 작성 | Word → PDF 변환 |
| 리뷰 요청 | 공유 리뷰 시작, 마크업 권한 설정 |
| 협업 리뷰 | 하이라이트, 스티키 노트, 취소선, 텍스트 교체 |
| 코멘트 수집 | 코멘트 통합, 필터링, 요약 |
| 수정 반영 | 코멘트 상태 변경 (Accepted/Rejected) |
| 최종 승인 | 디지털 서명 + 타임스탬프 |
| 보관 | PDF/A 변환, 장기 보관 |

## 2. 계약서 관리 워크플로우

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 계약서 작성 │ → │ PDF 변환  │ → │ 서명 필드  │
│ (Word)   │    │          │    │   추가    │
└──────────┘    └──────────┘    └──────────┘
                                      │
┌──────────┐    ┌──────────┐    ┌──────────┐
│   보관    │ ← │ 디지털 서명 │ ← │ 서명 요청  │
│ (LTV 포함)│    │ + 타임스탬프│    │ 라우팅    │
└──────────┘    └──────────┘    └──────────┘
```

### 서명 라우팅 방식

| 방식 | 설명 | 사용 예시 |
|------|------|-----------|
| **순차 서명** | 한 명이 서명 후 다음 사람에게 전달 | 상위 승인자부터 순서대로 |
| **병렬 서명** | 모든 서명자가 동시에 서명 | 동일 수준 관계자들 |
| **하이브리드** | 순차 + 병렬 조합 | 부서별 병렬 → 최종 순차 승인 |

## 3. 송장 처리 워크플로우

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ PDF 송장  │ → │   OCR    │ → │ 데이터 추출 │ → │ 승인 라우팅│
│  수신    │    │ (스캔 시)  │    │ (업체, 금액)│    │ (금액 기준)│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      │
                                ┌──────────┐          │
                                │   보관    │ ←────────┘
                                │ (베이츠 번호)│
                                └──────────┘
```

## 4. 법률 문서 워크플로우

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 문서 스캔  │ → │   OCR    │ → │ 베이츠 번호 │ → │ 편집 마스킹│
│          │    │ (검색 가능)│    │   적용    │    │ (민감정보) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      │
                                ┌──────────┐    ┌──────────┐
                                │ PDF 포트폴리오│ ← │ 보안 설정  │
                                │ (사건 파일)  │    │ (권한/암호)│
                                └──────────┘    └──────────┘
                                      │
                                ┌──────────┐
                                │ PDF/A 보관│
                                └──────────┘
```

### 법률 문서 핵심 기능

| 기능 | 설명 |
|------|------|
| **베이츠 번호** | 접두사 + 자동 증가 번호 (예: CASE001-000001) |
| **편집 마스킹** | 주민번호, 계좌번호 등 민감 정보 영구 삭제 |
| **검색 및 편집** | 패턴으로 민감 정보 자동 검색 후 일괄 마스킹 |
| **PDF 포트폴리오** | 관련 문서를 하나의 패키지로 관리 |

## 5. 건설/엔지니어링 워크플로우

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ CAD 도면   │ → │ PDF 변환  │ → │ 측정 교정  │ → │ 마크업/리뷰│
│  출력     │    │          │    │ (스케일)   │    │ (구름 주석)│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      │
                                ┌──────────┐    ┌──────────┐
                                │ 최종 평탄화 │ ← │ 리비전 추적│
                                └──────────┘    └──────────┘
```

### 건설 분야 전용 기능

| 기능 | 설명 |
|------|------|
| **측정 도구** | 거리, 면적, 둘레 정밀 측정 |
| **교정 (Calibration)** | 도면 축척 설정 |
| **구름 주석** | 수정 사항 표시 (건설 업계 표준) |
| **리비전 표시** | 변경 이력 관리 |

## 6. 일괄 처리 워크플로우 (Action Wizard)

| 작업 | 설명 |
|------|------|
| 일괄 OCR | 여러 스캔 문서를 한꺼번에 텍스트 인식 |
| 일괄 워터마크 | 문서 세트에 워터마크 일괄 적용 |
| 일괄 보안 설정 | 여러 문서에 동일한 보안 정책 적용 |
| 일괄 PDF/A 변환 | 여러 파일을 보관 표준으로 변환 |
| 일괄 압축 | 여러 PDF 동시 최적화 |
| 일괄 머리글/바닥글 | 여러 문서에 페이지 번호 추가 |

## 7. 문서 비교 워크플로우

| 비교 방식 | 설명 | 도구 |
|-----------|------|------|
| **텍스트 비교 (시맨틱)** | 텍스트 변경 사항 하이라이트 | Adobe Acrobat Compare |
| **이미지 오버레이** | 픽셀 단위 시각 비교 | diff-pdf |
| **나란히 보기** | 두 버전을 병렬 표시 | Draftable |
| **차이점 보고서** | 변경 사항 요약 보고서 생성 | Adobe Acrobat |

## 8. PDF 표준별 용도

| 표준 | 용도 | 핵심 요구사항 |
|------|------|---------------|
| **PDF/A-1** | 기본 보관 | 임베드 폰트, 암호화 금지, JS 금지 |
| **PDF/A-2** | 확장 보관 | 투명도, 레이어, PDF/A 파일 임베드 |
| **PDF/A-3** | 첨부파일 보관 | 임의 파일 첨부 허용 |
| **PDF/X** | 인쇄 제작 | 임베드 폰트, 정의된 색상, 투명도 금지 |
| **PDF/E** | 엔지니어링 | 3D 콘텐츠, CAD 도면 |
| **PDF/UA** | 접근성 | 전체 태그 구조, 읽기 순서, 대체 텍스트 |

## 9. PDF 포트폴리오

### 특징
- 여러 파일 유형 (PDF, Word, Excel, CAD)을 하나의 PDF로 패키징
- 각 파일이 원본 형식과 편집 가능성 유지
- 전체 포트폴리오에 일관된 보안 적용
- 커스텀 레이아웃으로 탐색 및 정리

### 활용 사례

| 사례 | 포함 파일 |
|------|-----------|
| 프로젝트 납품물 | 보고서(PDF), 데이터(Excel), 도면(CAD), 사진 |
| 법률 사건 파일 | 계약서, 증거, 진술서, 판례 |
| 입찰 문서 | 제안서, 견적서, 자격 증빙, 참고 자료 |
| 인사 파일 | 이력서, 포트폴리오, 자격증, 추천서 |

## @heureum/pdf에서 활용 가능한 기업 워크플로우

이 프로젝트의 도구를 활용한 자동화 시나리오:

### 폼 자동 입력 워크플로우
```
1. PDF 폼 분석
   pdf_check_fillable_fields → 폼 유형 판별
   ↓
2a. 정형 폼인 경우
    pdf_extract_form_fields → 필드 정보 추출
    pdf_fill_fields → 폼 데이터 자동 입력
    ↓
2b. 비정형 폼인 경우
    pdf_extract_form_structure → 시각적 구조 분석
    pdf_check_bounding_boxes → 위치 검증
    pdf_create_validation_image → 시각적 확인
    pdf_fill_annotations → 주석 기반 입력
    ↓
3. 결과 검증
   pdf_convert_to_images → 이미지로 변환하여 최종 확인
```

### AI 에이전트 기반 문서 처리
```
1. PDF 이미지 변환 (pdf_convert_to_images)
   → LLM이 문서 구조를 시각적으로 분석
   ↓
2. 폼 구조 추출 (pdf_extract_form_structure)
   → 라벨, 필드 위치, 체크박스 등 자동 식별
   ↓
3. AI가 입력값 결정
   → 컨텍스트 기반 자동 입력값 생성
   ↓
4. 폼 자동 작성
   → pdf_fill_fields 또는 pdf_fill_annotations
```
